H 图像质量设置（静态）· 25 项 Image Quality

格式与尺寸

  • 图像尺寸 L/M/S × 3:2 / 1:1 / 16:9
  • 图像质量 FINE / NORMAL / +RAW / RAW
  • RAW 录制：未压缩 / 无损压缩 / 压缩
  • 选择 JPEG / HEIF

色彩

  • 胶片模拟（19 种，见速查卡 05）
  • 黑白（暖冷 / 绿洋红微调）
  • 白平衡 + 微调 + 自定义 + 色温 K
  • 色彩效果 / 彩色 FX 蓝色
  • 色彩 −4…+4

影调

  • 动态范围 自动 / 100 / 200 / 400
  • D 范围优先级 关 / 弱 / 强 / 自动
  • 色调曲线 高光 −2…+4 · 阴影 −2…+4
  • 清晰度 −5…+5
  • 颗粒效果（粗糙度 × 尺寸）

细节与维护

  • 锐度 / 高 ISO 降噪（−4…+4）
  • 长时间曝光降噪 开/关
  • 镜头调整优化器 开/关
  • 色彩空间 sRGB / Adobe RGB
  • 像素映射（亮点消不掉时用）

自定义

  • 编辑/保存自定义设置（C1–C4）
  • 自动更新自定义设置 启用/禁用
  • 自定义模式设定（静态 / 视频）
  • 转接环设置（M 卡口镜头，6 组）

快捷键

  • Fn 拨盘＝最快换胶片模拟
  • RAW 指派给功能键＝临时 +RAW
  • 胶片模拟/白平衡也可指派 Fn
