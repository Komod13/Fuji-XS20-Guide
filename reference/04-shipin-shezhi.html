视频设置速查

视频菜单与照片菜单是两套。这一页把「三个入口 · 五个选项卡 · 两套配方」收在一处。

三个录制入口 Three Entries

入口怎么开始/结束适用
t 动画录制按钮照片模式下直接按 t拍照片途中随手录；自动切 AF-C
模式拨盘 → F（动画）用快门按钮完整控制视频设定
模式拨盘 → Vlog用快门按钮；设定走触控自拍、边走边讲
三者的设定分开存储。录制中屏幕显示 V 指示、边框变红（高速录制变绿），剩余时间倒计时、录制时间正计时。再次按同一按钮结束。

摄像模式与帧率 Mode & FPS

画面大小 / 纵横比

  • J 6.2K 3:2（裁切余量大，可后期转竖屏）
  • V 4K 16:9（主流交付）
  • d 4K 17:9（DCI 宽银幕）
  • W 全高清 16:9 / 17:9
  • S 全高清 16:9 / 17:9（可录更久）

帧率

  • 23.98P / 24P — 电影感
  • 25P / 50P — PAL 区、国内室内防频闪
  • 29.97P / 59.94P — NTSC

快门＝帧率两倍：25P→1/50，50P→1/100，24P→1/48 或 1/50。

高速录制（慢动作）

  • 仅全高清（W 16:9 / 17:9）
  • 记录：100P / 120P / 200P / 240P
  • 回放：23.98P–59.94P
  • 240P + 24P 回放 ＝ 10 倍慢放
  • 不录音；「仅限 HDMI 开启」不存卡

其他视频设置项

  • 拍摄模式：P / S / A / M（视频专用）
  • 背景散景模式（仅 Vlog 档）
  • F 自拍 3 / 5 / 10 s / 关
  • 视频裁剪放大 1.29× 开/关
  • 信号灯（指示灯 / AF 辅助灯）
  • 记录帧指示器 开/关

稳定与自动对焦 IBIS & AF

图像稳定

  • IBIS/OIS：常规手持
  • IBIS/OIS + DIS：走动拍摄（会裁切）
  • 关：三脚架
  • 增能 开＝不转动更稳；关＝适合摇镜
  • 镜头 O.I.S. 开关优先于菜单

Vlog 对焦

  • AF-C + 广域/跟踪 + 眼睛识别自动
  • AF-C 速度调慢→ 避免焦点呼吸
  • 产品测评：Vlog 档「产品优先模式 → 开」
  • 背景散景模式 → 开（光圈固定最大）
  • ISO 按钮在视频下打开视频 ISO
