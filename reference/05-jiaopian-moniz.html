黑白与滤镜 ACROS & B&W

两种黑白

  • ACROS：细节丰富、锐度高、颗粒极细 → 风光、建筑
  • 黑白：传统黑白，反差更直白
  • 棕褐色（sepia）
  • 黑白微调：WARM–COOL / G–M 轴（暖调 ↔ 冷调）

三种颜色滤镜

  • + 黄（Ye）：略增对比、稍暗天空 → 风光万金油
  • + 红（R）：强对比、天空大幅压暗 → 云层戏剧感
  • + 绿（G）：肤色更讨喜 → 黑白人像

白平衡搭配 White Balance

选项取向用法
自动中性自动默认
W A 白色优先白炽灯下也把白拍成亮白室内不想发黄
A A 环境优先保留现场暖调餐厅、咖啡馆、黄昏
自定义 1–3白纸/灰卡实测混色光、产品、接片
色温 K2500–10000 K（10 K 步进）精确控色，或故意偏暖/偏冷
日光 / 阴天 / 荧光灯 1–3 / 白炽灯 / 潜水固定预设光源明确稳定时
故意偏色：拍日落把白平衡固定为「日光」会更暖更艳；拍雪景固定「阴天」可防发灰——自动白平衡会「纠正」掉你要的气氛。
闪光与白平衡：只有自动 / 白 A / 环境 A / 潜水会按闪光灯调整白平衡；用其它固定项时请关闭闪光。

动态范围搭配 DR

场景建议
日出日落、想保对比DR100
白天高反差DR200（ISO ≥ 320）
正午强光、逆光DR400（ISO ≥ 640）或 D 范围优先级「弱」
极高反差、想同时保高光与阴影D 范围优先级「强」（ISO ≥ 640）
想自己控色调曲线D 范围优先级必须关
